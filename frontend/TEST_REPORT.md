# KW Meet · C드라이브 SSD 이전 및 검증

검증일: 2026-11-01 (Asia/Seoul)

## 완료한 작업

- 프로젝트: C:\Android\KWMeetApp
- SDK: C:\Android\Sdk
- 가상폰 및 기존 앱 데이터: C:\Android\AVD
- Android Studio / JBR: C:\Android\AndroidStudio
- Android 사용자 설정, 도구 및 Gradle 경로를 C:\Android 아래로 변경.
- 바탕화면 Run-Android.cmd, Start-KWMeet.cmd와 프로젝트/Android Studio 바로가기 갱신.
- D드라이브 원본 보존. 이 원본은 복사 시점의 백업이며 새 C드라이브 데이터와 자동 동기화하지 않습니다.

## 검증 범위의 한계

- 독립 실행 APK 및 실제 Android 기기 테스트는 수행하지 않았습니다.
- 동일 조건의 HDD/SSD 전후 속도, FPS 및 릴리스 성능 수치를 측정하지 않았습니다.
- Windows 가상폰 창 캡처가 `FrameArrived timed out` / `window capture timed out`으로 실패해 자동 좌표 터치 검사는 수행하지 않았습니다. 사용자 수동 확인과 자동 검증 결과를 구분해 기록했습니다.
- 실제 사용자 데이터에 대한 예약 생성/삭제 등 추가 조작은 하지 않았습니다.
- GitHub 업로드, 원격 저장소 연결, Push, PR 또는 EAS 업로드는 하지 않았습니다.

후속 변경: 새로운 모임의 기본 3명을 건우·승균·휘서로 변경했습니다. 기존 이름이 새로운 모임인 3인 모임에도 반영하며, 앞서 잘못 바꾼 오픈소스 프로젝트의 기본 이름은 복원합니다. 시간표·예약·별도 모임과 이후 사용자 수정을 보존하는 일회성 갱신을 검증했습니다.
