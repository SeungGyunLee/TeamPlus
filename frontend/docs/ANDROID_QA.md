# Android 수동 확인 체크리스트

아래 항목은 자동 통과를 주장하는 목록이 아닙니다. SDK 57 지원 Expo Go 또는 설치한 APK에서 직접 확인하세요.

- [ ] 360dp 이하 화면에서 요일·교시·셀 30개가 가로 잘림 없이 보인다.
- [ ] 팀원 이름 입력 시 키보드에 가려진 필드를 스크롤할 수 있다.
- [ ] 기기의 뒤로 가기로 모달 → 직전 화면 → 홈 순서로 돌아간다.
- [ ] 팀원 A 수업 셀을 변경해도 팀원 B의 시간표는 유지된다.
- [ ] 팀원 추가/삭제 직후 공강 수와 전체 인원이 변경된다.
- [ ] 전원 수업/전원 공강/일부 공강의 숫자와 팀원 목록이 정확하다.
- [ ] 공강 셀을 선택해도 예약 화면이 자동으로 열리지 않는다.
- [ ] 집현전 상세에서 예약 화면으로 이동한다.
- [ ] 팀 인원보다 작은 방, 예약됨, 지난 시간의 슬롯을 예약할 수 없다.
- [ ] 예약 확인 후 빠르게 두 번 눌러도 중복 예약되지 않는다.
- [ ] 예약 취소 후 같은 사용자 슬롯은 다시 예약할 수 있다.
- [ ] 앱을 완전히 종료하고 다시 열어 모임/시간표/예약/취소 내역이 유지된다.
- [ ] 설정에서 라이트/다크 전환 시 홈·그리드·예약 상태·모달·날짜·탭과 시스템 바를 읽을 수 있다.
- [ ] 시스템이 다크여도 최초 실행은 라이트다.
- [ ] 기기 설정에 따름 선택 후 Android 시스템 테마 변경을 즉시 반영한다.
- [ ] 테마를 바꾸어도 편집 중인 이름, 시간표와 예약은 남는다.
- [ ] Android의 애니메이션 삭제/동작 축소 설정에서 Reanimated 효과가 축소된다.
- [ ] TalkBack으로 셀의 요일·교시·참석 인원, 선택 상태, 버튼 의미를 알 수 있다.
- [ ] 글자 크기 확대 시 긴 팀원 이름·모임 이름이 겹치지 않는다.
- [ ] 비행기 모드에서도 핵심 기능이 동작한다 (최초 번들 로드 이후).

실패 시 기기/Android 버전, 화면, 재현 단계와 스크린샷을 남겨 수정하세요.
